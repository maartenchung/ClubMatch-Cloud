# Build 1800 release scope

- Live Actieveld reconciles field roster after every confirmed snapshot, so players can be substituted out/in repeatedly and remain selectable when on the field.
- Mobile and desktop support `player -> empty pitch location -> action`; role position remains unchanged while action x/y is stored.
- Late/guest player contract supports active players from the same club and season during live/halftime.
- Sportlink appears as planned/not connected; real sync is deferred to Stannet VPS.
- Youth substitution policy pilot: 25-50-65, equal minutes, development, load, tactical, custom.
- Dashboard match-to-training advice uses measured KPI weaknesses and shows data coverage.
- Match deletion verifies server absence before refreshing history and open-match views.
