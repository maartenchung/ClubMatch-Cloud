# ClubMatch Cloud v0.8 — build 20260828.2225

## Live UX

- Snelle registratie is de enige zichtbare live actiecatalogus.
- Actieve speler bij Spelerbezit bepaalt de actor voor eigen-teamacties; aparte speler-dropdown is verwijderd uit de live UX.
- Categorieën en A–Z blijven beschikbaar.
- Oude rode balverliesoorzaken zijn geïntegreerd als gewone acties: Foute pass, Pass onderschept, Balverlies · duel, Bal kwijt · controle, Bal kwijt · dribbel en Overig balverlies.
- Actieveld is uit de browser-shell gehaald; onderliggende gesture/event-contracten blijven als R&D en bestaande historie blijft leesbaar.

## Analistmodus

- A → B blijft pass geslaagd + pass ontvangen + nieuw spelerbezit + teambezit registreren.
- Goal gebruikt de actieve speler als scorer.
- Een recente pass ontvangen kan automatisch de aangever als assist koppelen.
- Goal registreert compound schot + schot op doel + goal via de bestaande backend-RPC.
- Kayden → Matz → Goal is als assistketen geautomatiseerd getest.

## Reliability

- De laatste overgebleven `client.rpc` monkeypatch in de refresh-warmup is verwijderd; startup warmt nu alleen read-only RPC-reads parallel op.
- Concurrente coachmutaties herkennen een verhoogde state_version, laden de nieuwste confirmed Cloud-status en melden dat de lokale actie niet is uitgevoerd.
- Realtime + polling fallback blijven ongewijzigd actief.
